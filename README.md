| День 2 | [`day2`](https://github.com/imarkelov/ai_advent_challenge/tree/day2) | Контроль ответа LLM: формат, лимит длины, условие завершения (stop) |
| День 3 | [`day3`](https://github.com/imarkelov/ai_advent_challenge/tree/day3) | Статичный web-интерфейс без сервера: 3 роли LLM (кинокритик, режиссёр, сценарист) + синтез главным промтом |
