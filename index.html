      Системный промпт

      Системный промпт — первое сообщение (role: system) в каждом запросе: задаёт роль и правила ответов агента. Остальные параметры, применяемые к каждому запросу:

      model
      модель, обрабатывающая запрос (выбирается в настройках);
      temperature
      случайность: 0 — детерминированный ответ, выше — разнообразнее; «не задано» — значение модели по умолчанию;
      max_tokens
      лимит длины генерации в токенах; «не задано» — без лимита;
      chat_template_kwargs.enable_thinking
      рассуждения (thinking): true/false — включает/выключает reasoning-токены модели;
      messages
      system-промпт + история диалога (последние 20 сообщений) + ваш вопрос.

      JSON API-запроса к LLM
