# Proposal: day11-memory-layers

## Why

Агент не различает типы памяти: вся информация живёт в диалоге (dialogues.json) и
теряется при закрытии диалога; долговременной памяти (профиль, решения, знания),
переживающей все диалоги и рестарт, нет; пользователь не управляет тем, что
сохраняется и куда. Задание дня 11: явная модель памяти (memory layers) — минимум
3 типа памяти, хранимые отдельно, с выбором пользователем, что куда сохраняется,
и проверкой влияния слоёв на ответы агента.

## What Changes

- **3 слоя памяти в 3 отдельных хранилищах**: краткосрочная (ST) — сообщения
  активного диалога (`dialogues.json`, существует); рабочая (WM) — данные текущей
  задачи (цель/стек/ограничения/дедлайн), новое `working_memory.json`, per-dialogue;
  долговременная (LT) — профиль/решения/знания, новое глобальное `memory.json`,
  переживает все диалоги и рестарт сервера.
- **Подсистема памяти становится единственным ассамблером контекста** LLM-запроса:
  стратегии дня 10 (`legacy` / `sliding_window` / `branching`) становятся
  **режимами краткосрочного слоя**; система day9-сжатия остаётся механикой режима
  `legacy`.
- **BREAKING**: `sticky_facts` исключается из реестра режимов ST — её функция
  (извлечение фактов ТЗ) поглощается рабочим слоем: схема фактов WM = FACT_KEYS
  дня 10, формат инъекции «Актуальные факты:» = формат WM-блока. Старые диалоги с
  `strategy: "sticky_facts"` мигрируются при загрузке (режим → `sliding_window`,
  факты → `working_memory.json`), только в памяти, закрепляются обычным save.
  `POST /agent/strategy/switch` с `"sticky_facts"` → 400 (RU-сообщение).
- **Контроль пользователя — 3 механизма**: (1) **routing-правила** —
  редактируемая карта `категория → working | long_term | dialogue_only` для
  авто-извлечения (LLM-вызов после каждого user-хода, паттерн facts.py: маркер +
  fallback без исключений), дефолт выключен; (2) **явное действие** — «Запомнить»
  на сообщении с выбором слоя (без LLM); (3) **тумблеры** — какие слои
  инжектятся в payload (WM/LT) + авто-извлечение вкл/выкл.
- **Инъекция в payload**: непустые WM/LT-слои добавляются в system-промт блоками
  (при включённом тумблере); пустой слой = блока нет. Дефолты: авто-извлечение
  OFF, инъекция ON → при пустых слоях **legacy payload остаётся
  byte-identical** (locking-тест не ломается).
- **API**: `GET /agent/memory` (содержимое 3 слоёв + настройки модели),
  `POST /agent/memory/save` (ручной save), `POST /agent/memory/routing`
  (правила), `POST /agent/memory/settings` (тумблеры),
  `DELETE /agent/memory/{layer}` (сброс слоя).
- **UI** (index.html): панель «Память» — 3 слоя с содержимым, routing-редактор,
  тумблеры, кнопка «Запомнить» на сообщении; селектор «Стратегия» →
  «Режим краткосрочной» (3 опции).
- **Проверка** (шаблон дня 10): `benchmark_day11.py --mock`
  (детерминированный сценарий, метрики: routing-точность, инъекция слоёв в
  payload, персистентность LT между диалогами) и `--real` (демонстрация влияния
  на ответ: диалог 1 формирует профиль/решение → новый диалог, LT вкл/выкл →
  разные ответы), `scripts/e2e_day11.py`, секция «День 11» в README.

## Capabilities

### New Capabilities

- `memory-layers`: явная модель памяти агента — 3 слоя в отдельных
  хранилищах, режимы краткосрочного (бывшие стратегии дня 10), routing
  авто-извлечения, ручной save, тумблеры инъекции, инъекция WM/LT-блоков в
  system-промт, REST-API памяти, UI-панель, совместимость (legacy byte-identical,
  дефолты off, миграция sticky_facts).

## Impact

- **Код**: `memory.py` (новый модуль — менеджер памяти), `agent.py`
  (ask() собирает контекст через менеджера памяти; миграция sticky_facts при
  загрузке), `strategies.py` (реестр: 3 режима ST; класс StickyFactsStrategy —
  только для миграции/совместимости), `facts.py` (схема извлечения расширяется
  категориями LT — profile/decisions/knowledge), `main.py` (маршруты
  `/agent/memory*`), `index.html` (панель памяти).
- **Данные**: новые файлы `working_memory.json`, `memory.json` (в `.gitignore`);
  `dialogues.json` — additive-миграция ключа `strategy` старых sticky_facts-диалогов.
- **API**: новые эндпоинты `/agent/memory*`; `POST /agent/strategy/switch` —
  BREAKING для `"sticky_facts"` (→ 400).
- **Инварианты (обязательны)**: legacy payload byte-identical
  (tests/test_legacy_payload.py), новые фичи дефолт OFF
  (tests/test_defaults_off.py), request-journal и day10-эндпоинты branching —
  без изменений.
- **Тесты/проверка**: новые `tests/test_memory_*.py` (офлайн, fake-LLM по
  паттерну install_fake), `benchmark_day11.py`, `scripts/e2e_day11.py`.
