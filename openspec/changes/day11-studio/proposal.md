# Proposal: day11-studio

## Why

Модель памяти дня 11 реализована на ветке `day11` поверх стека дней 1–10
(`http.server` + `index.html`, stdlib). Новое задание: переработать интерфейс и
стек технологий, сделать 11-й день **самостоятельным приложением**, которое не
наследует код и механики дней 1–10 (сжатие, стратегии, авто-извлечение,
routing). Референс `xfrwrd/ai-advent-9` (Streamlit + requests + python-dotenv,
явная ручная память) проанализирован и использован как источник идей, но стек
меняется: **FastAPI + React (Vite)**. Памятью управляет человек вручную.

## What Changes

- Новая ветка `day11-studio` от `master` и новая папка `studio/`
  (`backend/` + `frontend/` + `data/`) — код дней 1–10 и ветки `day11`
  не наследуется и не трогается.
- **Бэкенд (FastAPI)**: чат с GPustack (OpenAI-совместимый API) с
  SSE-стримингом; 3-слойная память с ручным CRUD; журнал API-запросов;
  токен-статистика; список моделей; в prod — статическая отдача собранного
  фронтенда.
- **Фронтенд (React + Vite + TypeScript)**: раскладка «Студия» — три панели:
  слева диалоги + сводка памяти, в центре чат, справа панель «Контекст» с
  вкладками Память / Токены / Запрос. Тема — mid-dark (фон #1e1e24, панели
  #26262e, границы #3a3a44), чистый CSS с дизайн-токенами (CSS-переменные),
  без UI-фреймворков.
- **Память — 3 слоя, управление ручное** (без авто-извлечения и routing):
  - «Диалог» (hover: Short-Term Memory) — сообщения активного диалога, clear;
  - «Текущая задача» (hover: Working Memory) — key/value, per-dialogue,
    добавить/удалить/clear;
  - «Долговременная» (hover: Long-Term Memory) — key/value, глобально,
    добавить/удалить/clear.
  - Непустые WM/LT инъектируются блоками в system-промпт; у каждого слоя —
    число записей и оценка размера в токенах.
- **Token HUD**: prompt / reasoning / total / лимит контекста; вкладка
  «Токены» — развёрнутая статистика (оценка по слоям, кумулятивно за сессию).
- **Запросы**: toggle «показывать/скрыть»; аннотированный вид — у каждого
  параметра запроса короткое пояснение «что это» (словарь — отдельный
  расширяемый файл на фронте); неизвестные параметры показываются со значением
  и пометкой «(доп. параметр, без описания)»; журнал всех запросов с
  timestamp, каждый раскрывается; пояснения для usage (prompt_tokens /
  completion_tokens / total_tokens).
- **Хранилище**: JSON-файлы в `studio/data/` (диалоги, working, longterm,
  requests), атомарная запись; файлы в `.gitignore`.
- **Проверка**: pytest (бэкенд, офлайн fake-LLM), Vitest smoke (фронтенд),
  `scripts/e2e_studio.py`, секция «День 11: студия» в README.

## Capabilities

### New Capabilities

- `studio-app`: самостоятельное приложение дня 11 «Студия» — FastAPI + React
  (Vite/TS), 3-слойная память с ручным управлением и инъекцией в
  system-промпт, SSE-чат, Token HUD, аннотированный журнал запросов с
  fallback-пометкой для неизвестных параметров, JSON-хранилище, mid-dark UI.

## Impact

- **Код**: новая самодостаточная папка `studio/`; существующие файлы (день
  10/master) не изменяются.
- **Данные**: `studio/data/*.json` (в `.gitignore`); `.env` — существующие
  `GPUSTACK_API_KEY` / `GPUSTACK_BASE_URL`.
- **Зависимости**: бэкенд — `fastapi`, `uvicorn`, `httpx`; фронтенд —
  `react`, `react-dom`, `vite`, `typescript`, `vitest` (dev).
- **Процессы**: dev — `uvicorn` :8000 + `vite` :5173 (прокси `/api`); prod —
  один `uvicorn` (статика из `frontend/dist`).
